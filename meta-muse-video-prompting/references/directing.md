# 장면 연출 · 씨댄스 2.5에서 각색

이 문서는 서비스 독립적인 작성 규칙이다. 모델별 기능과 길이는 SKILL.md 및 현재 서비스 설정을 우선한다.

## 입력과 현재 요청

이미지는 실제로 확인하고 인물·의상·초기 자세·손과 물체의 접촉·시선·광원·공간을 읽는다. 파일명은 이미지의 관찰 근거가 아니다. 이야기만 있으면 가상 첨부를 만들지 않는다. 이야기와 이미지가 함께 있으면 사건은 이야기에서, 지정된 외모·구도·공간은 이미지에서 가져온다.

현재 장면에서 확정된 길이·음향·동작 조건을 후속 수정에도 유지한다. 특정 장면의 조건을 모든 미래 영상의 고정 길이나 음악 금지로 확대하지 않는다. 새 요청의 명시 조건이 우선한다.

### 참조 역할과 보존 범위

참조마다 얼굴·의상·공간·첫 프레임·카메라·동작·스타일 중 주 역할과 변경 가능한 부분을 구분한다. 얼굴 참조에서 배경을 자동 상속하지 않고, 동작 참고 영상에서 얼굴과 음악을 가져오지 않는다. 여러 이미지를 자동으로 연속 프레임으로 취급하지 않는다.

REF LOCK에는 실제 첨부의 이름이나 UI에 확인된 표기, 유지 속성, 허용 변화와 충돌 우선순위를 짧게 적는다. 다른 모델의 @이미지1 문법을 대상 서비스의 지원 문법이라고 단정하지 않는다. UI 태그가 없으면 ‘첨부 이미지’처럼 사람이 식별 가능한 이름을 사용한다. 영상의 첫 프레임으로 사용할 의도를 적는 것과 실제 첫 프레임 제어가 지원되는 것은 구별한다.

### 행동과 감정

- 인물의 동작과 카메라 움직임을 따로 쓴다. 바람·나비·입자·카메라 이동만으로 인물이 움직인다고 설명하지 않는다.
- 동작이 요구되면 초기 자세에서 가능한 주 행동을 정한다. ‘신비롭다’ 대신 ‘몸을 앞으로 기울여 꽃 아래를 손끝으로 스친 뒤 손을 들어 올리고, 눈으로 빛을 따라간다’처럼 몸의 변화가 보이게 쓴다.
- 감정은 계기 → 시선 또는 호흡의 첫 변화 → 손·얼굴·자세 반응 → 끝 상태로 드러낸다. 모든 장면에 미소·눈물·떨림을 일괄 추가하지 않는다. 사용자가 정지 연기를 원하면 존중한다.
- 접촉 전 상태 → 접촉 → 힘의 방향 → 물체 반응 → 접촉 후 상태를 연결한다. 이미 손에 쥔 물체를 다시 집게 하지 않는다. 손가락 수·팔다리·소품의 연결 관계를 자연스럽게 유지한다.
- 짧은 클립에는 읽히는 핵심 행동과 반응을 선택한다. 길이가 짧다는 이유로 모든 움직임을 미세한 흔들림으로 줄이거나, 많은 행동을 급하게 몰아넣지 않는다.

### 타임라인과 끝 상태

사용자 길이를 그대로 유지하고 0초부터 종료까지 공백·중복 없이 배분한다. 5초 장면은 예컨대 0–2초 접근/접촉, 2–4초 변화와 반응, 4–5초 끝 자세로 설계할 수 있다. 이는 예시이며 모든 장면의 공식이 아니다. 첫 이미지의 실제 포즈에서 시작한다.

마지막 비트에 손의 위치·시선·물체 상태·빛의 상태를 명시하고 카메라 끝 구도는 카메라 절에 쓴다. 기존 8초를 5초로 바꾸면 옛 시간표와 그에 의존한 동작·초점·음향 지시도 함께 교체한다. 요청 없이 슬로모션이나 자동 분할로 길이를 채우지 않는다.

### 카메라와 공간

장면에서 관객이 무엇을 알아차려야 하는지 정한 뒤 카메라를 선택한다. 고정 숏도 유효하다. 이동이 필요하면 시작 구도 → 한 가지 주 이동 → 방향/경로/속도 → 초점 → 끝 구도로 쓴다. 주체의 회전과 카메라의 오빗, 본체 접근과 광학 줌, 팬과 옆 이동, 초점 변경을 구분한다.

원테이크는 이동과 인물 상태가 비트 사이에 물리적으로 이어져야 한다. 나무·어둠·안개를 숨은 컷으로 사용하지 않는다. 편집을 요청했으면 컷 시점과 다음 시작 구도를 쓰고 영화 같다는 이유로 원샷으로 바꾸지 않는다. 대화·대치·추격은 행동축, 화면 좌우, 시선, 진행 방향과 카메라 쪽을 고정한다. 요청한 축 넘기나 오빗은 그 전환과 이후 공간 관계를 설계한다.

액션은 준비/접근 → 접촉/충격 → 몸과 물체의 결과 → 회복으로 연결한다. 카메라는 사건을 읽을 수 있게 반응하고 충격 이전에 결과를 보여주지 않는다. 액션이 없는 장면에 과격한 흔들림을 추가하지 않는다.

### 조명과 질감

LIGHTING LOCK에 주 광원의 위치·방향·색·부드러움·명암과 허용 변화를 적는다. ‘청록색’ 같은 색상만으로 조명을 대체하지 않는다. 꽃의 발광이면 빛의 증가가 꽃에서 시작해 가까운 손과 얼굴에 약하게 반사되도록 한다. 원래 달빛과 배경 노출은 유지하고 전체 화면이 갑자기 밝아지지 않게 한다.

영화 같은 질감을 요청하고 별도 질감 지시가 없으면 넓은 공간 깊이, 풍부한 중간톤, 부드러운 하이라이트, 미세한 유기적 필름 그레인과 밝은 부분의 은은한 할레이션을 선택할 수 있다. IMAX 65mm 등의 표현은 미적 의도이며 실제 장비·인증·출력 사양을 뜻하지 않는다. 원본 유지·디지털 클린·애니메이션 요청이 우선한다.

### 시각 효과와 장르

효과는 시작 상태 → 발동 계기 → 변형 대상/과정 → 도달 상태로 묘사한다. 프리셋 이름만 쓰지 않는다. 손·꽃·빛·카메라를 별도 움직이는 층으로 구별한다. 얼굴 보존 규칙이 사용자가 의도한 변신 자체를 막지 않도록 변화 영역과 유지 영역을 나눈다.

영화는 목적·사건·관찰 가능한 반응·마지막 변화를 중심에 둔다. 티저는 단서와 미해결 질문, 정보 공개 순서를 지킨다. 광고는 제품 형태·라벨·효익이 보이는 순간을 확보한다. 뮤직비디오는 실제 확인한 음원의 변화와 퍼포먼스를 연결한다. 듣지 않은 곡의 BPM·박자 시각을 만들지 않는다. 연주는 손과 악기의 접촉, 춤은 무게중심과 착지, 가창은 원본 발화·쉼·호흡의 시간을 존중한다. 수집 사례를 새 영상의 검증된 생성 결과라고 부르지 않는다.

### 오디오 계약

아래 모드를 구분하고 사용자가 선택한 것만 적용한다.

- NO BGM: 배경음악 없이 허용된 대사와 지정한 물리적 현장음만. 음악 금지는 자동으로 대사·노래·모든 효과음 금지를 뜻하지 않는다.
- 완전 무음: 음악·대사·호흡·효과음·현장음을 모두 끈다. 빈 공간을 룸톤으로 채우지 않는다.
- 원본 오디오만: 지정한 실제 소스의 내용과 내부 시간을 보존하고 생성 음향을 덧붙이지 않는다. 원본에 음악이 있으면 그대로 유지하는 것과 음악 제거는 다른 작업이다.
- 무반주 보컬: 요청한 노래는 유지하고 반주·추가 음악을 배제한다.
- 음악 포함: 요청한 곡이나 음악 방향을 유지한다. 영화·뮤직비디오라는 장르명만으로 음악을 추가하거나 삭제하지 않는다.

NO BGM에서는 들리는 소리의 물리적 원인을 구체적으로 적는다. 빛 입자가 보인다는 이유로 자동으로 마법 종소리나 음악적 패드를 추가하지 않는다. 음악 삭제 수정 시 박자 동기화·스웰·음악 분위기 등 종속 지시도 제거한다. 실제 서비스에 음악 끄기 설정이 있으면 선택 여부를 확인한다. 프롬프트의 금지 문장만으로 음악이 제거됐다고 보장하지 않는다.

### 전체 프롬프트 형식

장면 프롬프트는 다음 8개 절을 순서대로 하나의 복사 블록에 작성한다. 짧은 장면에는 각 절을 짧게 쓰되 불필요한 기법·제약 목록으로 늘리지 않는다. 대사가 있으면 발화 대본과 제작 지시를 분리한다.

1. 참조: 실제 자료의 역할, 유지 속성, 변경 범위, REF LOCK.
2. 피사체: 정체성·외형·초기 자세·목적.
3. 배경: 장소·시간·공간 관계·기준물.
4. 타임라인: 요청 길이, 비트별 주체 행동과 반응, 마지막 물리 상태.
5. 카메라: 시작·주 이동 또는 고정·경로·속도·초점·끝·컷 정책.
6. 스타일: 질감·색·재질, LIGHTING LOCK.
7. 오디오: 실제 소스 역할, 대사·현장음·음악/무음, AUDIO LOCK.
8. 제약 조건: 화면비·연속성·FRAME LOCK과 현재 필요한 금지 사항.

설정 요약 한 줄 → 복사용 완성 프롬프트 → 필요한 짧은 설명으로 전달한다. 씨댄스의 5,000자 작성 예산이나 모델별 길이 제한을 대상 서비스 공식 제한으로 가져오지 않는다. 현재 입력란의 실제 제한이 있으면 그 안에서 핵심 동작과 음향을 보존해 압축한다.

### 후속 수정과 검수

가장 최근 지시를 반영한 현재 유효 브리프 하나를 만든다. 추가/교체/삭제/재배치/시간 변경을 구분한다. 삭제된 행동의 효과음·초점·따라가는 카메라도 함께 제거한다. 음악 삭제, 길이 변경, 끝 상태 변경은 종속된 시간을 다시 설계한다. 과거 지시를 부정문으로 계속 남기지 않는다.

수정 시 일부 패치만 주지 말고 복사 가능한 전체 교체 프롬프트를 반환한다. 첫 실패부터 해당 층의 원인을 좁혀 보강하며 관련 없는 연출은 유지한다. 보지 못한 결과를 진단 완료했다고 말하지 않는다. 프롬프트 수정만 요청받았으면 생성이나 유료 재시도를 하지 않는다.

반환 전 확인: 실제 참조만 있는가? 요청 시간 전체를 덮는가? 인물 행동이 카메라와 분리되어 보이는가? 시작 자세에서 가능한가? 접촉과 물체 반응이 이어지는가? 카메라·컷·공간이 충돌하지 않는가? 조명 변화가 국소적인가? NO BGM/완전 무음/소스 전용을 혼동하지 않았는가? 끝 상태가 분명한가?
